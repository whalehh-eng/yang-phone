# 杨博文的虚拟 iPhone

纯 HTML/CSS/JavaScript 单页网站，无需安装依赖、账号或 API 密钥。GitHub Pages 从 main 分支根目录发布。

- 打开页面直接显示锁屏，无开机姓名或加载动画。点击锁屏、底部横条或上滑，再输入四位密码 0601。支持鼠标点击、触屏点按与实体键盘。
- 默认蓝色锁屏、两块桌面组件、18 种官方 App Store 应用图标。
- 网易云音乐可进入，内容待补充；航海王热血航线、作业帮和学习通仅显示图标。
- 丰台区、南岸区天气按季节和昼夜本地模拟，可左右滑动切换，非实时天气。
- 备忘录可编辑、搜索、置顶和删除；照片支持用户主动选择导入。数据在刷新后清除。
- 不会拨打电话、发送短信或获取真实位置，不包含人物真实私密内容。密码只是互动剧情机制，不保护任何真实数据。
- 图标原始文件内嵌，不依赖运行时外部请求；来源见“官方图标来源.json”。
- 用户此前上传的壁纸保留在图片预览分支，但按最新要求默认恢复蓝色锁屏。

本地查看可双击 index.html，或在本目录运行 python3 -m http.server 4180。localhost 仅适用于运行服务器的同一台电脑。

## 解锁与布局修复

数字键与备忘录置顶使用独立事件，防止按钮事件冲突。已逐个点击测试 0601、错误密码、删除及重新锁屏。桌面机身宽 460px，窄屏接近满宽，不再按窗口高度缩小手机；保持机身比例，必要时页面可滚动。
